Gesture Mouse

Control your mouse with your hand.

A small, free tool that turns your webcam into a mouse. Move your index finger to move the cursor, pinch to click, and hold up two fingers to scroll — no extra hardware needed.

Download for your laptop View on GitHub

Gestures

  • Move— point your index finger, the cursor follows
  • Click— pinch your thumb and index finger together
  • Scroll— hold up your index and middle fingers

Run it locally

  1. Download the ZIP above and unzip it, or clone the repo.
  2. Install Python if you don't already have it.
  3. Open a terminal in the gesture-mouse folder and run: 
    pip install -r requirements.txt
python gesture_mouse.py
  4. On Windows, you can also just double-click start.bat.
Works on Windows, macOS, and Linux with a webcam and Python installed.
